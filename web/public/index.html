Features

Everything you need, nothing you don't.

Otter is built for the moment you need to get a file from one device to another, right now.

Live activity

Watch every transfer as it happens, with progress, speed, and an ongoing notification on Android.

Nearby discovery

Devices on the same Wi-Fi find each other automatically. No pairing codes, no setup.

Gallery-ready

Received photos and videos are saved straight into your Gallery, not buried in a download folder.

Private by design

Transfers run over HTTPS between your own devices. Each device has its own certificate fingerprint.

Clean history

Every sent and received file is listed with its status. Clear the history whenever you want.

Web hub

No app on the other device? Open the address Otter shows in any browser and send files from there.

How it works

Three steps. Under a minute.

  1. 1

    Install Otter

    Get the app for each device. It runs quietly in the menu bar, tray, or background.

  2. 2

    Make sure you're on one Wi-Fi

    Both devices need to be on the same network. Otter shows the others as Nearby Devices.

  3. 3

    Pick a device and send

    Choose your files. Watch progress live. Save what you received with one tap.

Install

Step-by-step, per platform.

Your system may warn about apps from outside its store. Otter is safe to run; these steps tell your system so.

macOS
  1. Unzip Otter-macOS.zip and open Otter.dmg, then drag Otter into Applications. Or Homebrew: run brew tap elmeeee/grasp-drop https://github.com/elmeeee/Grasp-drop.git && brew install --cask otter.
  2. The first time, macOS may say the app can't be checked. Right-click Otter in Applications, choose Open, then Open again.
  3. Allow Local Network and Notifications when asked. Otter appears in the menu bar.
Android
  1. Unzip Otter-android.zip on the phone and open Otter-android.apk.
  2. If prompted, allow installs from your browser or file manager.
  3. Allow notifications when Otter asks. This shows live transfer progress.
Windows
  1. Unzip Otter-windows-cli.zip. It contains otter.exe.
  2. Open a terminal in that folder and run otter.exe. Allow access on private networks when Windows Firewall asks.
  3. To send a file: otter.exe --send 192.168.1.42 photo.jpg.
Linux
  1. Unzip Otter-linux-x64.zip and run chmod +x Otter-linux-x64.
  2. Start it with ./Otter-linux-x64. Open UDP and TCP port 53317 and TCP 7456 if a firewall is active.
Network tip: both devices must be on the same Wi-Fi, and the router must not isolate clients (AP isolation). Guest networks often block device-to-device traffic.

FAQ

Questions

Does Otter need the internet?

No. Files go directly from one device to another over your local network. An internet connection is not needed.

Is my data uploaded anywhere?

No. Otter has no cloud service and no account. Files are never sent to our servers.

Can I send to an iPhone or iPad?

Yes, through the web hub. Open the address Otter shows in Safari on the device and upload or download files from there.

Is Otter compatible with LocalSend?

No. Otter uses its own protocol, which is modelled on the same idea. Otter devices talk to other Otter devices.

Where do received files go?

On Mac, into ~/Downloads/Otter. On Android, photos and videos go to your Gallery and other files to Downloads when you tap Save.
