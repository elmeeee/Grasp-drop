Features

Everything you need.
Nothing you don't.

Built for the moment you need a file on another device, right now.

Live activity

Watch every transfer with progress and speed. Android keeps it in the notification shade.

Nearby discovery

Devices on the same Wi-Fi find each other automatically. No pairing codes, no setup.

Gallery-ready

Photos and videos go straight into your Gallery, not buried in a download folder.

Private by design

Transfers run over HTTPS between your own devices. Each device has its own certificate fingerprint.

Clean history

Every sent and received file is listed with its status. Clear it whenever you want.

Web hub

No app on the other device? Open the address Otter shows in any browser and send from there.

How it works

Three steps. Under a minute.

  1. 1

    Install Otter

    Get the app for each device. It runs quietly in the menu bar, tray, or background.

  2. 2

    Join one Wi-Fi

    Both devices need to be on the same network. The others appear as Nearby Devices.

  3. 3

    Pick a device and send

    Choose files, watch progress live, and save what you receive with one tap.

Install

Step by step.

Your system may warn about apps from outside its store. These steps tell it Otter is safe to run.

macOS
  1. Unzip Otter-macOS.zip, open Otter.dmg, and drag Otter into Applications.
  2. The first time, right-click Otter in Applications, choose Open, then Open again.
  3. Allow Local Network and Notifications when asked. Otter appears in the menu bar.
  4. Or Homebrew: brew tap elmeeee/grasp-drop https://github.com/elmeeee/Grasp-drop.git && brew install --cask otter
Android
  1. Unzip Otter-android.zip and open Otter-android.apk.
  2. If prompted, allow installs from your browser or file manager.
  3. Allow notifications when Otter asks. This shows live transfer progress.
Windows
  1. Unzip Otter-windows-cli.zip. It contains otter.exe.
  2. Open a terminal in that folder and run otter.exe. Allow private network access when Windows Firewall asks.
  3. To send: otter.exe --send 192.168.1.42 photo.jpg
Linux
  1. Unzip Otter-linux-x64.zip and run chmod +x Otter-linux-x64.
  2. Start it with ./Otter-linux-x64. Open UDP and TCP port 53317, and TCP 7456, if a firewall is active.
Network tip: both devices must be on the same Wi-Fi, and the router must not isolate clients (AP isolation). Guest networks often block device-to-device traffic.

FAQ

Questions

Does Otter need the internet?

No. Files go directly from one device to another over your local network.

Is my data uploaded anywhere?

No. Otter has no cloud service and no account. Files never reach our servers.

Can I send to an iPhone or iPad?

Yes, through the web hub. Open the address Otter shows in Safari on the device and upload or download there.

Where do received files go?

On Mac, into ~/Downloads/Otter. On Android, photos and videos go to your Gallery and other files to Downloads when you tap Save.
